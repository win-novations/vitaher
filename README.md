# VitaHer

The **SheCare** women's health companion app — a self-contained single-page
prototype. *Know Today. Prevent Tomorrow. Thrive Always.*

## Live

- Render: https://vitaher.onrender.com
- Portal mirror: https://portal.winnovations.co.za/shecare/

## Stack

A single, dependency-free `index.html` — all CSS, JavaScript and SVG are inline.
No build step, no backend.

## Deploy (Render static site)

Render auto-deploys this repo via `render.yaml`:

- **Type:** static site
- **Build command:** none
- **Publish directory:** `.` (repo root)

Pushing to `main` triggers a redeploy.
